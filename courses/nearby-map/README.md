# 내 주변을 탐색하는 지도 — 소스

JavaSchool `내 주변을 탐색하는 지도` 6강에서 쓰는 소스입니다. 서버 없이 브라우저만으로 돌아갑니다.

## 두 벌이 들어 있습니다

| 폴더 | 무엇 | 언제 |
|---|---|---|
| `starter/` | 1강을 시작할 때의 파일 | **여기서 시작합니다** |
| 이 폴더 | 6강까지 끝낸 최종본 | 따라 치다 어긋났을 때 맞춰 봅니다 |

## 시작하기

1. 이 저장소를 내려받거나 `git clone` 합니다.
2. `starter/` 폴더를 통째로 복사해 원하는 자리에 둡니다.
3. 그 폴더의 `index.html`을 Chrome 또는 Edge로 엽니다.
4. 강의를 따라가며 `app.js`, `index.html`을 채웁니다.

`starter/`에는 app.js (비어 있음), index.html, style.css이 들어 있습니다. 강의가 직접 치게 하는 코드는 빼 두었습니다.

## 실행 환경

- Chrome 또는 Edge
- 설치할 것 없음. 빌드 도구도 서버도 쓰지 않습니다.

## 막혔을 때

강의 화면 아래의 `완성 소스` 링크가 이 폴더를 가리킵니다. 파일을 나란히 열어 다른 줄을 찾습니다.
