# 같이 듣는 곡을 한 목록에 모으기 — 소스

JavaSchool `같이 듣는 곡을 한 목록에 모으기` 6강에서 쓰는 소스입니다. 서버 없이 브라우저만으로 돌아갑니다.

## 두 벌이 들어 있습니다

| 폴더 | 무엇 | 언제 |
|---|---|---|
| `starter/` | 1강을 시작할 때의 파일 | **여기서 시작합니다** |
| 이 폴더 | 6강까지 끝낸 최종본 | 따라 치다 어긋났을 때 맞춰 봅니다 |

## 시작하기

1. 이 저장소를 내려받거나 `git clone` 합니다.
2. `starter/` 폴더를 통째로 복사해 원하는 자리에 둡니다.
3. 그 폴더에서 간단한 서버를 켭니다. 파일을 두 번 눌러 열면 마지막 수업에서 만들 링크가 `file://`이 되어 다른 사람에게 보낼 수 없습니다.

```bash
python3 -m http.server 4322
```

4. 브라우저에서 `http://localhost:4322`를 엽니다.
5. 강의를 따라가며 `app.js`, `index.html`을 채웁니다.

`starter/`에는 app.js (비어 있음), index.html, style.css이 들어 있습니다. 강의가 직접 치게 하는 코드는 빼 두었습니다.

## 실행 환경

- Chrome 또는 Edge
- 폴더를 열어 줄 간단한 서버 하나. 위의 `python3`가 없으면 `npx serve`나 편집기의 미리보기 기능도 됩니다.
- 빌드 도구는 쓰지 않습니다. 고친 파일을 새로고침하면 바로 보입니다.

## 막혔을 때

강의 화면 아래의 `완성 소스` 링크가 이 폴더를 가리킵니다. 파일을 나란히 열어 다른 줄을 찾습니다.
